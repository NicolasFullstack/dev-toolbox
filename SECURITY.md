# Sécurité

Les exemples ne doivent jamais contenir de mot de passe, de clé API ou d'identifiant réel.

Les secrets sont placés dans des variables d'environnement. Les entrées utilisateur sont validées et les requêtes SQL utilisent des paramètres préparés. Les mots de passe sont traités avec les fonctions de hachage natives du langage.
