# Règles d'ajout

Chaque ajout doit :

1. répondre à un besoin précis ;
2. contenir une explication simple ;
3. proposer un exemple minimal ;
4. signaler les points de sécurité ;
5. indiquer les erreurs fréquentes ;
6. être testé avant le commit.

Les messages de commit restent courts et décrivent une seule évolution.
